คำแนะนำสำคัญ: ใช้แผ่นเทมเพลตเดิมทุกครั้ง, ถ่ายภาพให้เห็นจุดมาร์กครบทั้ง 4 มุม, วางกล้องให้ใกล้กึ่งกลาง และหลีกเลี่ยงแสงสะท้อนบนผิวหลุม เพื่อให้การอ่านสีแม่นขึ้น ถ้าตรวจมุมอัตโนมัติไม่สำเร็จ ให้คลิกมุมเองตามลำดับซ้ายบน → ขวาบน → ขวาล่าง → ซ้ายล่าง
กฎการอ่านผลแบบใหม่: สีแดง/ชมพูที่ยังไม่มีสัญญาณน้ำเงินเพิ่มจาก 0 mg/L = โซน 0 · จากนั้นสีเปลี่ยนเป็นม่วงและน้ำเงินเข้มขึ้น = Blue Signal เพิ่ม โปรแกรมจะเทียบการเปลี่ยนค่า b* กับมาตรฐาน 0, 1, 2, 4, 6, 8 mg/L ในภาพเดียวกัน โดยตรวจว่ามาตรฐานเรียงตัวเพิ่มขึ้นจริงก่อนรายงานค่า
